# structurizr-dsl-cli

Check, summarise and resolve Structurizr DSL files from the command line. No dependencies; Node 18+.

    structurizr-dsl check workspace.dsl
    structurizr-dsl resolve workspace.dsl -o workspace.json

Run `structurizr-dsl --help` for all commands and options. Exit codes: 0 ok, 1 the DSL has errors, 2 bad usage.
